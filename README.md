# キャプチャ録画タイマー

USB接続の外部映像キャプチャデバイスの**映像・音声**を、**終了タイマー付き**で録画・録音するブラウザツールです。
単一のHTMLファイル（[`capture-recorder.html`](./capture-recorder.html)）だけで動作し、録画データは外部に送信されません。

👉 **[ツールを開く（GitHub Pages）](https://yoppyy.github.io/capture-recorder/capture-recorder.html)**

## 特徴

- 映像＋音声（WebM / MP4）の録画、または音声のみ（MP3）の録音
- 3種類の終了条件
  - 録画時間（時・分・秒）で終了
  - 終了時刻で終了（過ぎている時刻は翌日扱い）
  - 上記の終了条件に加えて、音が出たあと無音が指定秒数（初期値30秒）続いたら自動終了（オン/オフ可）
- MP3録音時に、最初と最後の無音を自動カット（オン/オフ可、音の前後に約1秒の余白を残す）
- 分割保存（指定した分ごとに別ファイル化）
- 開始前カウントダウン、録画中の画面スリープ防止、終了時のビープ音
- 自動終了後にPCをスリープ／シャットダウン（付属ヘルパー使用）
- 映像・音声デバイスの選択、解像度・FPS・画質の設定
- 録音音量の設定（0〜150%。MP3録音は録音中も変更可）
- プレビュー音量の調整
- すべての設定（デバイス、解像度、録画形式、終了条件、無音設定、保存方法など）をブラウザに記憶し、次回起動時に復元

## 動作環境

- PCのChrome（推奨）
- カメラとマイクの使用許可が必要です（[Chromeでカメラとマイクを使用する](https://support.google.com/chrome/answer/2693767?hl=ja)）。
- `https://` または `localhost` で開くのが確実です（上記の公開ページは `https://` なので、許可や設定が保持されます）。`file://` でも動作しますが、許可や設定の保存が保持されないことがあります。
- MP3録音は、変換ライブラリ（lamejs）をCDNから読み込むため、インターネット接続が必要です。

## 使い方

1. [公開ページ](https://yoppyy.github.io/capture-recorder/capture-recorder.html) （またはダウンロードした [`capture-recorder.html`](./capture-recorder.html)）をChromeで開きます。
2. **① 検出＋プレビュー開始** を押し、カメラとマイクの使用を許可します。デバイス検出とプレビューまで自動で行います。
3. 映像デバイス・音声デバイスを選びます。解像度やFPSを変えると、プレビューは自動で切り替わります。
      - 切り替えをやり直したいときは **② プレビュー再開始** を使います。
4. **録画形式**（映像＋音声 / 音声のみ MP3）と**終了条件**を設定します。
5. **● 録画開始**（音声のみのときは **● 録音開始**）を押すと、カウントダウン後に録画が始まります。
6. 条件を満たすと自動で停止し、ファイルがダウンロードされます。**■ 停止** で手動停止もできます。

## 終了後にPCをスリープ／シャットダウンする

ブラウザ単体ではPCの電源操作はできないため、付属のヘルパー [`capture_helper.py`](./capture_helper.py)（Python 3）を使います。

1. 録画の前に、ヘルパーを起動しておきます。
   ```
   python capture_helper.py
   ```
   動作確認だけしたいときは `python capture_helper.py --dry-run`（実際には操作しません）。
2. ツールの「自動終了後のPC操作」で、スリープまたはシャットダウンを選びます。「✅ ヘルパーに接続できました」と出れば準備完了です。
3. タイマーまたは無音で**自動終了**すると、ファイルの保存完了を待ってから、設定した猶予（初期値60秒）のカウントダウンが始まります。「キャンセル」を押すと中止できます。

**注意**
- **■ 停止**で手動停止したときは、PC操作は実行しません。
- ヘルパーは `127.0.0.1`（このPC）だけで待ち受け、許可したページ（公開ページ、localhost）からの依頼だけを受け付けます。`file://` で開いている場合は `--allow-file`、別のページから使う場合は `--allow-origin https://...` を付けて起動してください。
- 自動ダウンロードで保存している場合、ダウンロードの完了を待てません。大きなファイルは、**保存先フォルダを指定**するか、猶予を長めにしてください。
- 対応OS：Windows（スリープ・シャットダウン）、macOS、Linux。Windowsでは、休止状態（ハイバネーション）の設定によってスリープの挙動が変わることがあります。
- ヘルパーを起動していない、または接続できない場合は、PC操作は実行されません。

## 設定項目

| 項目 | 内容 |
|---|---|
| 解像度 | 自動 / 3840×2160 / 1920×1080 / 1280×720 / 640×480 |
| FPS | 60 / 30 / 24 |
| 画質（Mbps） | 映像のビットレート（4 / 8 / 16 / 25） |
| 録音音量 | 0〜150%（初期値100%）。録音・録画される音声の音量。プレビュー音量とは別 |
| 録画形式 | 映像＋音声（WebM/MP4）、音声のみ（MP3） |
| 映像の保存形式 | WebM（標準・安定） / MP4（H.264） |
| MP3ビットレート | 128 / 192 / 256 / 320 kbps |
| 分割保存 | 指定した分ごとに別ファイル化（0で無効） |
| 開始前カウントダウン | 秒数（初期値3） |
| 終了条件（タブ） | 録画時間で終了（初期値1時間） / 終了時刻で終了 |
| 自動終了（無音で終了） | オン/オフ（初期値オン） |
| 無音が続く時間 | 自動終了までの秒数（初期値30） |
| 自動無音カット | MP3録音の前後の無音カットのオン/オフ（「無音の設定」） |
| 自動終了後のPC操作 | 何もしない / スリープ / シャットダウン（要ヘルパー） |
| 実行までの猶予 | 操作を実行するまでの秒数。この間にキャンセルできます（初期値60） |
| 無音と判定する音量 | 「無音の設定」。-40dB / -50dB（標準） / -60dB。自動終了と自動カットの両方で使います |

## 無音の扱い

- **自動終了**：「自動終了（無音で終了）」がオンのとき有効です。録音開始後、最初に音が出るまでは無音判定をしません。一度音が出たあと、無音が指定秒数続くと停止します。終了タイマーは上限として働きます。
- **自動カット（MP3のみ）**：先頭は音が出始める約1秒前から保存し、末尾は最後に音があった約1秒後で切ります。カットは約85ミリ秒単位のブロックで行うため、境界は厳密ではありません。
- **分割保存との併用**：先頭は最初に音が出るまで、末尾は最後のパートだけカットします。途中の無音は切りません。
- すべて無音のパートは保存されません。

## 保存形式

- 映像＋音声：WebM（VP8/Opus）が標準です。MP4（H.264）も選べますが、環境によっては録画データが得られないことがあります（その場合は自動でWebMに切り替わります）。MP4が必要な場合は、録画後にffmpegなどで変換してください。
- 音声のみ：MP3
- ファイル名：`capture_日時_p1.mp4`（`p1` は分割時のパート番号）

## Python版（画面つき・ヘルパー内蔵）

ブラウザ版と同じことを、PC上のアプリとして行う版です。[`capture_recorder.py`](./capture_recorder.py) 1ファイルで動き、**スリープ／シャットダウンの機能も内蔵**しています（別のヘルパーは不要）。ブラウザの制限（タブが裏に回る、許可が毎回出る、など）を受けません。

**準備**
1. Python 3.9以降をインストールします。
2. ffmpegをインストールし、PATHに通します（Windowsなら `winget install ffmpeg` など）。
3. `pip install -r requirements.txt`（numpy、sounddevice）

**起動**
```
python capture_recorder.py
```
画面が開きます。ブラウザ版と同じ項目（終了条件、無音で自動終了、無音カット、録音音量、終了後のPC操作など）を設定して「● 開始」を押します。設定は `~/.capture_recorder.json` に記憶されます。

| 形式 | 取り込み・保存 | 無音カット | 無音で自動終了 |
|---|---|---|---|
| 音声のみ（MP3） | sounddeviceで取り込み、ffmpegでMP3に変換 | ○ | ○ |
| 映像＋音声（MP4） | ffmpegで直接録画（Windowsは DirectShow） | × | ○（ffmpegのsilencedetect） |

- 映像録画のときは、映像デバイスと音声デバイスの両方を、一覧（「更新」ボタン）から**同じ名前のまま**選んでください。
- 保存は、保存先フォルダに `capture_日時.mp3` / `.mp4` として行います。

**コマンドライン版**
```
python capture_recorder.py --list-devices
python capture_recorder.py --cli --mode mp3 --device 1 --duration 3600 --silence-stop 30 --power sleep --dry-run
```
`--dry-run` を付けると、スリープ／シャットダウンは実行せず、実行予定のコマンドだけを表示します。`--help` で全オプションを確認できます。

**動作確認（セルフテスト）**
```
python capture_recorder.py --selftest
```
疑似音源とffmpegで、無音カット、無音での自動終了、音量、動画の自動終了を確認します。

## トラブルシューティング

**映像は出るが音が出ない／音声レベルのバーが動かない**
- 音声デバイスの欄で、キャプチャデバイス側の入力（USB Audio、デジタル オーディオ インターフェイスなど）を選び直してください。
- Windowsの「設定 → プライバシーとセキュリティ → マイク」で、アプリのマイク使用が許可されているか確認してください。
- アドレスバー左のアイコン →「サイトの設定」で、カメラとマイクが「許可」になっているか確認してください（[参考：Chromeのヘルプ](https://support.google.com/chrome/answer/2693767?hl=ja)）。
- 映像ソース側（ゲーム機など）の音声出力が有効か確認してください。

**録音・録画の途中が早送りのようになる／音が飛ぶ**
- 録音中にPCがスリープや省電力状態に入ると、その間のデータが欠けて、再生時に早送りのように聞こえることがあります。長時間録る場合は、Windowsの「電源とスリープ」でスリープを「なし」にしてください。
- MP3録音では、受信した音の長さが実時間より明らかに短いとき、終了時に「音声が約◯秒分欠落した可能性があります」と表示します。
- MP3録音の音声取り込みは、公開ページ（HTTPS）では欠落に強い方式（AudioWorklet）を使います。`file://` で開くと従来方式になり、PCが忙しいときに音が飛びやすくなります。
- 映像録画では、PCの負荷が高いとフレームが落ちて途中が飛んで見えることがあります。解像度を1280×720に下げる、FPSを30にする、画質（Mbps）を下げる、といった設定で改善することがあります。

**許可ダイアログが毎回出る**
- `file://` で開いていると、許可が保持されないことがあります。GitHub PagesなどHTTPSのページに置くと保持されます。

**MP3録音を開始できない**
- 変換ライブラリの読み込みにインターネット接続が必要です。接続を確認してください。

**長時間の録画**
- 録画データは終了までメモリに保持されます。1〜2時間を超える場合は、分割保存を使ってください。
- 録画中はタブを閉じたり、PCをスリープさせたりしないでください。
