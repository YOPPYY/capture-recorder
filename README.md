# キャプチャ録画タイマー

USB接続の外部映像キャプチャデバイスの**映像・音声**を、**終了タイマー付き**で録画・録音するブラウザツールです。
単一のHTMLファイル（[`capture-recorder.html`](./capture-recorder.html)）だけで動作し、録画データは外部に送信されません。

👉 **[ツールを開く（GitHub Pages）](https://yoppyy.github.io/capture-recorder/capture-recorder.html)**

## 特徴

- 映像＋音声（MP4 / WebM）の録画、または音声のみ（MP3）の録音
- 3種類の終了条件
  - 録画時間（時・分・秒）で終了
  - 終了時刻で終了（過ぎている時刻は翌日扱い）
  - 音が出たあと、無音が指定秒数（初期値60秒）続いたら自動終了
- MP3録音時に、最初と最後の無音を自動カット（音の前後に約1秒の余白を残す）
- 分割保存（指定した分ごとに別ファイル化）
- 開始前カウントダウン、録画中の画面スリープ防止、終了時のビープ音
- 映像・音声デバイスの選択、解像度・FPS・画質の設定
- プレビュー音量の調整（設定は記憶されます）

## 動作環境

- PCのChrome（推奨）
- カメラとマイクの使用許可が必要です（[Chromeでカメラとマイクを使用する](https://support.google.com/chrome/answer/2693767?hl=ja)）。
- `https://` または `localhost` で開くのが確実です（上記の公開ページは `https://` なので、許可や設定が保持されます）。`file://` でも動作しますが、許可や設定の保存が保持されないことがあります。
- MP3録音は、変換ライブラリ（lamejs）をCDNから読み込むため、インターネット接続が必要です。

## 使い方

1. [公開ページ](https://yoppyy.github.io/capture-recorder/capture-recorder.html) （またはダウンロードした [`capture-recorder.html`](./capture-recorder.html)）をChromeで開きます。
2. **① 検出＋プレビュー開始** を押し、カメラとマイクの使用を許可します。デバイス検出とプレビューまで自動で行います。
3. 映像デバイス・音声デバイスを選びます。解像度やFPSを変えると、プレビューは自動で切り替わります。
   - 切り替えをやり直したいときは **② プレビュー再開始** を使います。
4. **録画形式**（映像＋音声 / 音声のみ MP3）と**終了条件**を設定します。
5. **● 録画開始** を押すと、カウントダウン後に録画が始まります。
6. 条件を満たすと自動で停止し、ファイルがダウンロードされます。**■ 停止** で手動停止もできます。

## 設定項目

| 項目 | 内容 |
|---|---|
| 解像度 | 自動 / 3840×2160 / 1920×1080 / 1280×720 / 640×480 |
| FPS | 60 / 30 / 24 |
| 画質（Mbps） | 映像のビットレート（4 / 8 / 16 / 25） |
| 録画形式 | 映像＋音声（MP4/WebM）、音声のみ（MP3） |
| MP3ビットレート | 128 / 192 / 256 / 320 kbps |
| 分割保存 | 指定した分ごとに別ファイル化（0で無効） |
| 開始前カウントダウン | 秒数（初期値3） |
| 無音が続く時間 | 自動終了までの秒数（初期値60） |
| 無音と判定する音量 | -40dB / -50dB（標準） / -60dB |

## 無音の扱い

- **自動終了**：録音開始後、最初に音が出るまでは無音判定をしません。一度音が出たあと、無音が指定秒数続くと停止します。終了タイマーは上限として働きます。
- **自動カット（MP3のみ）**：先頭は音が出始める約1秒前から保存し、末尾は最後に音があった約1秒後で切ります。カットは約85ミリ秒単位のブロックで行うため、境界は厳密ではありません。
- **分割保存との併用**：先頭は最初に音が出るまで、末尾は最後のパートだけカットします。途中の無音は切りません。
- すべて無音のパートは保存されません。

## 保存形式

- 映像＋音声：ブラウザが対応していればMP4（H.264）、非対応ならWebM
- 音声のみ：MP3
- ファイル名：`capture_日時_p1.mp4`（`p1` は分割時のパート番号）

## トラブルシューティング

**映像は出るが音が出ない／音声レベルのバーが動かない**
- 音声デバイスの欄で、キャプチャデバイス側の入力（USB Audio、デジタル オーディオ インターフェイスなど）を選び直してください。
- Windowsの「設定 → プライバシーとセキュリティ → マイク」で、アプリのマイク使用が許可されているか確認してください。
- アドレスバー左のアイコン →「サイトの設定」で、カメラとマイクが「許可」になっているか確認してください（[参考：Chromeのヘルプ](https://support.google.com/chrome/answer/2693767?hl=ja)）。
- 映像ソース側（ゲーム機など）の音声出力が有効か確認してください。

**許可ダイアログが毎回出る**
- `file://` で開いていると、許可が保持されないことがあります。GitHub PagesなどHTTPSのページに置くと保持されます。

**MP3録音を開始できない**
- 変換ライブラリの読み込みにインターネット接続が必要です。接続を確認してください。

**長時間の録画**
- 録画データは終了までメモリに保持されます。1〜2時間を超える場合は、分割保存を使ってください。
- 録画中はタブを閉じたり、PCをスリープさせたりしないでください。
